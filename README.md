# CineWave Login System

A simple full-stack login authentication project built using React, Node.js, and Express.

## Features

* Modern Login UI
* Form Validation
* Toast Notifications
* Axios API Integration
* Express Backend
* Dashboard Redirect
* Responsive Design

## Technologies Used

### Frontend

* React.js
* Vite
* Tailwind CSS
* Axios
* React Router DOM

### Backend

* Node.js
* Express.js
* CORS

## Project Structure

```text
Frontend (React)
    ↓
Axios API
    ↓
Backend (Node.js + Express)
    ↓
Authentication
    ↓
Dashboard
```

## Run Frontend

npm install
npm run dev

## Run Backend

npm install
npm start
